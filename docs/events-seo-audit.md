## Автоматизация и безопасность

- `EVENTS_DATABASE_URL` позволяет подключить отдельную Neon-базу, не изменяя существующее хранилище видео.
- Идемпотентная миграция: таблица версионированного состояния и постоянные изображения. Миграция не выполняется самопроизвольно при обращении к странице.
- Обновления состояния сохраняются атомарным сравнением версии; конфликт повторяется до пяти раз. Параллельные задачи ограничены арендой блокировки со случайным токеном.
- Cron защищён bearer-секретом минимум 32 символа и безопасным сравнением. Отсутствующая конфигурация закрывает endpoint с 503, неверный токен — с 401.
- Изменения в админке требуют существующей сессии и совпадающего Origin. Публичное чтение внутренних очередей/журнала запрещено.
- При недоступной настроенной БД возвращается ошибка: пользовательские сохранённые изменения не заменяются незаметно исходным массивом.
- Импорт разрешён только по явно подтверждённому HTTPS JSON-фиду, с белым списком хостов, таймаутом, ограничением размера и запретом redirects/HTML. Все новые и изменённые события попадают на подтверждение. Отсутствие записи в фиде не означает отмену.
- Повторы подавляются отпечатками содержимого, стабильными slug и проверкой одинакового названия/даты/места. Смена `verifiedAt` сама по себе не создаёт дубль.
- Успешный плановый запуск отмечается ключом местного дня; есть время последней задачи, журнал до 200 сообщений, проверка ссылок на сохранённые изображения и вычисляемый архив.
- Источник пока не подключён. Режим `manual-only` **не является** автоматической перепроверкой расписания организаторов.

Подробная настройка и приёмка: [events-setup.md](events-setup.md). По умолчанию Cron 04:00 UTC, совместимый с ежедневной частотой Hobby, но зимой это 06:00, летом 07:00 и минута не гарантирована. Для тарифа с несколькими запусками предусмотрен фильтр местного часа `06` и расписание 03:00/04:00 UTC.
