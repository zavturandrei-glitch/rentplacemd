## Защита и публичные переходы

- Существующая защита: пароль администратора, подписанная HMAC-сессия, HttpOnly / SameSite=Lax cookie, Secure в production, срок сессии 14 дней. Секреты и настройки доступа не менялись.
- Справочник расположен в серверном модуле с `server-only`; доступ к данным каждый раз проверяет существующий `requireAdmin()`. Никаких открытых API для него не добавлено.
- Без сессии и с неверной сессией возвращается только вход, без рабочих ссылок. Проверены HTML и RSC. Авторизованные ответы имеют `Cache-Control: private, no-cache, no-store...`.
- Ссылки удалены из публичных структур данных и JSON-LD, а не только скрыты стилями. Проверены 100 страниц на пяти языках, 45 клиентских файлов сборки и sitemap. Рабочие ссылки отсутствуют; админка отсутствует в sitemap.
- Карты, фактические описания мест, ссылки на музеи и пограничную службу сохранены. Кнопки организации ведут в форму RentPlaceMD с выбранным маршрутом. Информационные направления дают возможность задать нам вопрос без обещаний организации.
- Фактический вход существующим паролем, неверный пароль, выход и повторный анонимный доступ проверены локальными HTTP-запросами. В браузере проверены закрытая форма входа и справочник с девятью номерами при активной сессии.
