## Аналитика

Используется существующая GA4 `G-404L3B7Q2R`; новый счётчик или платный сервис не устанавливался. Добавлен один делегированный обработчик кликов с очисткой при размонтировании и отдельное событие формы. Локальные и preview-хосты не отправляют custom events и не выполняют GA4 config.

| Точное имя | Когда срабатывает | Значение |
| --- | --- | --- |
| `tourism_to_apartments` | Нажатие ссылки из экскурсии, гида или событий на `/apartments` либо его категорию | Переход к выбору жилья |
| `apartment_view_click` | Нажатие ссылки на конкретную `/apartment/...` | Интерес к квартире |
| `contact_click` | Нажатие WhatsApp или `tel:` | Намерение связаться; не доказательство сообщения/звонка |
| `excursion_request` | Валидное нажатие отправки формы экскурсии, перед открытием WhatsApp | Передача запроса в WhatsApp; не подтверждение отправленного сообщения и не бронь |

Параметры: `source_path`, `language`; по ситуации `destination_path`, `journey_origin`, `contact_method`, `route_id`. Не передаются даты, число гостей, текст WhatsApp, телефон и пользовательский ввод. Источник туристического пути сохраняется в sessionStorage для последующего контакта на странице квартиры.

Повтор одного и того же события с теми же параметрами в одной вкладке/сессии не отправляется снова, включая возврат на страницу и перерисовку. При недоступном sessionStorage действует дедупликация в памяти. Новый маршрут/назначение — отдельное действие. Клики стандартного Enhanced Measurement `click` и наши события не следует складывать как отдельные заявки. Просмотр страницы не считается заявкой.

**Где смотреть после деплоя:** GA4 → Reports → Realtime; для отладки — Admin → Data display → DebugView с Google Analytics Debugger/Tag Assistant. Затем Reports → Engagement → Events или Admin → Data display → Events. В Explore можно построить путь `tourism_to_apartments` → `apartment_view_click` → `contact_click`. Для разрезов зарегистрировать event-scoped custom dimensions `source_path`, `destination_path`, `journey_origin`, `route_id`, `contact_method`. Не помечать page_view ключевым событием. При желании `excursion_request` можно отметить как key event с пониманием, что измеряется переход в WhatsApp, а не оплаченная экскурсия.

[GA4: события](https://support.google.com/analytics/answer/9322688?hl=en), [DebugView](https://support.google.com/analytics/answer/7201382?hl=en).

### IndexNow

Существующий `scripts/submit-indexnow.mjs` оставлен: публичный ключ уже находится в `public`, новый не создавался. Он принимает только `https://rentplace.md`, отклоняет localhost, сторонние домены, служебные пути, редиректы; перед POST проверяет опубликованный ключ и HTTP 200 страниц. Это публичный ключ владения, не секрет API. Кабинетные ключи/пароли не нужны и не добавлены.

Короткий приоритетный набор — шесть семейств страниц выше и исправленные UK URL квартир 77/78; все **32 точных адреса** находятся в [priority-urls.txt](priority-urls.txt). Отправлять только после проверки, что опубликована именно новая версия. Другие реально изменённые канонические статьи при необходимости добавить отдельно; noindex-автопрокат, robots и sitemap в пакет HTML-страниц не включать.

PowerShell, сначала просмотр без сети:

```powershell
$tourismUrls = Get-Content -LiteralPath 'docs/tourism-seo-audit/priority-urls.txt'
node scripts/submit-indexnow.mjs --dry-run @tourismUrls
```

Только после деплоя и проверки страниц:

```powershell
node scripts/submit-indexnow.mjs @tourismUrls
```

HTTP 200 — пакет принят; 202 — принят, проверка ключа ожидается. Оба ответа не подтверждают индексацию. При 403/422 проверить ключ и URL, при 429 прекратить повторы и дождаться разрешённого повторного запроса. Не отправлять неизменённые URL после каждого просмотра/деплоя. IndexNow уведомляет поддерживающие системы, **не Google**. [Документация](https://www.indexnow.org/documentation), [FAQ](https://www.indexnow.org/faq).
